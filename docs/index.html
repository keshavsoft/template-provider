⚙️ How It Works 💡 Why Use This Repo

Repository: KSCHEMA-API-GEN-APPJS

This repository automates Express.js route generation. By running the test runner in V2, it dynamically creates folders and populates them with boilerplate router.js files for modular API endpoints.

How the Script Works

When you execute test/v2/testrouter.js, the generator logic creates a new folder (e.g., folder3) and automatically scaffolds a router.js file inside it. This file contains a ready-to-use Express Router export.

Step-by-Step Execution Guide

  1. Step 1: Install Dependencies

    From the project root, install required packages:

    npm install
  2. Step 2: Review the Test Script

    Open test/v2/test.js. It imports runSync from index.js and configures folder generation:

    import { runSync } from "../..//index.js";

const startFunc = () => {
    const fromNpm = runSync({
        folderName: "folder3",
        toPath: process.cwd(),
        showLog: false,
        isAnnounce: true
    });
    console.log("Created router: ", fromNpm);
    return fromNpm;
};

startFunc();
  3. Step 3: Run the Script

    Execute the test runner:

    node test/v2/test.js
  4. Step 4: Verify Generated Router

    After execution, check your file tree. A new folder is created with a router.js file: 

    kschema-api-gen-appjs/
├── folder3/
│   └── router.js

Generated Router Example

import express from 'express';

const router = express.Router();

export { router };

Configuration Note: You can adjust folderName, toPath, and other parameters in test/v2/test.js to generate routers in different directories or with custom logging behavior.
